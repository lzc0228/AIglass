- 依靠 "Bounding Box Area" 判断距离在 3D 空间中不严谨

**Visual Proximity Score:** A coarse closeness score estimated via a class-aware pinhole projection using object pixel height and class priors (e.g., average pedestrian height) with known camera intrinsics, rather than relying on bounding-box area.

- 原始公式使用了冗长的连乘拼接 (W_{task} \times W_{scene}...)，不够优雅。

使用连乘符号 \prod 并集合化权重因子：

S_i = \text{Conf}_i \cdot \prod_{k \in \mathcal{K}} W_k(c_i, s, \dots)

Where \mathcal{K} = \{task, scene, user, prox, dyn\} represents the set of influence factors.
